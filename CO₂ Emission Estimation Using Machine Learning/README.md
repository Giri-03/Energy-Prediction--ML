
# 🌍 CO₂ Emission Estimation using Energy Data

## 🔍 Overview

This project aims to **estimate CO₂ emissions** based on **energy consumption data** using **Machine Learning techniques**.  
It is developed under the **AICTE–Edunet Internship (Energy Domain)** to analyze the relationship between energy usage patterns and carbon emissions, helping to promote sustainable energy practices.

---

## 🎯 Objectives

- Analyze and preprocess real-world energy consumption data.
- Build a predictive machine learning model to estimate CO₂ emissions.
- Visualize energy–emission correlations using data dashboards.
- Deploy a Flask-based web interface for easy model interaction.

---

## 🧠 Features

- 📊 Interactive dashboard with data visualization.
- ⚙️ Machine Learning pipeline for emission estimation.
- 🧹 Automated data preprocessing and feature engineering.
- 🖥️ Flask web app for prediction and result visualization.
- 📈 Model performance analysis (MAE, RMSE, R²).
